# Update v4: Rekap Iuran Tahunan

Fitur Tambahan:
- **Rekap Iuran Tahunan (Jan-Des):** Tampil di halaman Dashboard berbentuk *list* (daftar) memanjang vertikal yang elegan.
- *List* akan menampilkan rincian dari Januari hingga Desember di tahun berjalan (sekarang 2026).
- Bulan-bulan ke depannya (seperti November-Desember) akan disesuaikan menjadi mode transparan (abu-abu).
- Status **Lunas** (hijau) akan muncul otomatis jika seluruh karyawan sudah melunasi iurannya pada bulan tersebut, sebaliknya akan berstatus **Belum Lunas** (merah).
